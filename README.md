# Wern Styles

Wern Styles is a modern and responsive fashion website that showcases different clothing styles such as Bohemian, Casual, Formal, Streetwear, Vintage, Sporty, Romantic, and Electric styles.

The project was built using HTML, CSS, and JavaScript with a clean and user-friendly design. It includes interactive features such as Dark Mode, Search Functionality, Add to Cart, Favorite Items, Newsletter Subscription, and a Contact Form.

## Features

* Responsive design for desktop, tablet, and mobile devices.
* Smooth navigation between sections.
* Dark Mode toggle.
* Search system for fashion items.
* Add to Cart functionality with a cart counter.
* Favorite items system.
* Newsletter subscription form.
* Contact form interface.
* Modern UI with attractive fashion-focused layouts.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Purpose

This project was created to practice Front-End Web Development skills and build an interactive fashion website with a modern user experience.
